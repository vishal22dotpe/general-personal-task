## 📦 Method 1: Classic HTTP Repository

### How It Works:

```
Classic Repo Structure:
━━━━━━━━━━━━━━━━━━━━━━

  https://charts.example.com/
  ├── index.yaml              ← Index of ALL charts & versions
  ├── my-app-1.0.0.tgz       ← Packaged chart v1.0.0
  ├── my-app-1.1.0.tgz       ← Packaged chart v1.1.0
  ├── my-app-2.0.0.tgz       ← Packaged chart v2.0.0
  └── other-chart-1.0.0.tgz  ← Another chart


  When you do 'helm repo add' + 'helm repo update':
  
  ┌──────────┐    "Give me index.yaml"    ┌──────────────┐
  │  Helm    │──────────────────────────→│  HTTP Server  │
  │  Client  │                            │  (charts.    │
  │          │◄──────────────────────────│   example.com)│
  │          │    Returns index.yaml      └──────────────┘
  │          │    (list of all charts)
  └──────────┘

  When you do 'helm install my-app repo/my-app':

  ┌──────────┐    "Give me my-app-2.0.0.tgz" ┌──────────────┐
  │  Helm    │──────────────────────────────→│  HTTP Server  │
  │  Client  │                                └──────────────┘
  │          │◄── Downloads .tgz, unpacks, installs
  └──────────┘
```

### Creating a Classic Repo (GitHub Pages):

```bash
# Step 1: Create a GitHub repo for your charts
# e.g., github.com/myorg/helm-charts

# Step 2: Package your charts
helm package ./my-app-chart    # Creates my-app-1.0.0.tgz
helm package ./other-chart     # Creates other-chart-1.0.0.tgz

# Step 3: Move .tgz files to a directory
mkdir -p docs/
mv *.tgz docs/

# Step 4: Generate index.yaml
helm repo index docs/ --url https://myorg.github.io/helm-charts

# Step 5: Commit and push
git add docs/
git commit -m "Add chart packages"
git push

# Step 6: Enable GitHub Pages (Settings → Pages → Source: docs/)

# Step 7: Now users can add your repo!
# helm repo add myorg https://myorg.github.io/helm-charts
# helm install my-app myorg/my-app
```

### index.yaml Structure:

```yaml
# index.yaml (auto-generated by 'helm repo index')
apiVersion: v1
entries:
  my-app:
    - apiVersion: v2
      appVersion: "4.5.6"
      created: "2026-09-21T10:00:00Z"
      description: My awesome application
      digest: sha256:abc123...
      name: my-app
      type: application
      urls:
        - https://myorg.github.io/helm-charts/my-app-2.0.0.tgz
      version: 2.0.0
    - apiVersion: v2
      appVersion: "4.0.0"
      created: "2026-08-15T10:00:00Z"
      description: My awesome application
      digest: sha256:def456...
      name: my-app
      urls:
        - https://myorg.github.io/helm-charts/my-app-1.0.0.tgz
      version: 1.0.0
  other-chart:
    - apiVersion: v2
      name: other-chart
      version: 1.0.0
      urls:
        - https://myorg.github.io/helm-charts/other-chart-1.0.0.tgz
generated: "2026-09-21T10:00:00Z"
```

## 📦 Method 2: OCI Registry (Modern & Recommended ✅)

```
┌──────────────────────────────────────────────────────────────────┐
│                   OCI-BASED HELM CHARTS                          │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Since Helm 3.8+, OCI support is STABLE and RECOMMENDED        │
│                                                                  │
│  Benefits:                                                       │
│  ✅ Use SAME registry as Docker images                          │
│  ✅ No separate index.yaml maintenance                          │
│  ✅ Standard OCI distribution spec                              │
│  ✅ Better auth (same as docker login)                          │
│  ✅ Immutable tags support                                      │
│  ✅ Supported by all major cloud registries                     │
│                                                                  │
│  Supported registries:                                           │
│  • Docker Hub                                                    │
│  • GitHub Container Registry (ghcr.io)                          │
│  • AWS ECR                                                       │
│  • Google Artifact Registry                                      │
│  • Azure ACR                                                     │
│  • JFrog Artifactory                                             │
│  • Harbor                                                        │
│  • GitLab Container Registry                                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### OCI Workflow:

```bash
# ═══════════════════════════════════════════════════════
# PUSH chart to OCI registry
# ═══════════════════════════════════════════════════════

# 1. Login to registry
helm registry login ghcr.io -u myuser
helm registry login docker.io
helm registry login 123456789.dkr.ecr.us-east-1.amazonaws.com

# 2. Package your chart
helm package ./my-chart
# Output: my-chart-1.2.3.tgz

# 3. Push to registry
helm push my-chart-1.2.3.tgz oci://ghcr.io/myorg/charts

# Chart is now at:
# oci://ghcr.io/myorg/charts/my-chart:1.2.3

# ═══════════════════════════════════════════════════════
# PULL / INSTALL from OCI registry
# ═══════════════════════════════════════════════════════

# Pull (download)
helm pull oci://ghcr.io/myorg/charts/my-chart --version 1.2.3

# Install directly
helm install my-app oci://ghcr.io/myorg/charts/my-chart --version 1.2.3

# Show chart info
helm show chart oci://ghcr.io/myorg/charts/my-chart --version 1.2.3
helm show values oci://ghcr.io/myorg/charts/my-chart --version 1.2.3

# Template
helm template my-app oci://ghcr.io/myorg/charts/my-chart --version 1.2.3

# ═══════════════════════════════════════════════════════
# NOTE: No 'helm repo add' needed for OCI!
# You reference the full OCI URL directly.
# ═══════════════════════════════════════════════════════
```

### OCI vs Classic Comparison:

```
┌──────────────────────┬──────────────────────┬───────────────────────┐
│                      │  Classic HTTP Repo   │  OCI Registry         │
├──────────────────────┼──────────────────────┼───────────────────────┤
│ Setup                │ Web server +         │ Any container         │
│                      │ index.yaml           │ registry              │
├──────────────────────┼──────────────────────┼───────────────────────┤
│ Index                │ Manual index.yaml    │ No index needed!      │
│                      │ generation           │ (registry handles it) │
├──────────────────────┼──────────────────────┼───────────────────────┤
│ helm repo add        │ Required             │ NOT needed            │
├──────────────────────┼──────────────────────┼───────────────────────┤
│ Auth                 │ Basic auth / custom  │ docker login / cloud  │
│                      │                      │ IAM                   │
├──────────────────────┼──────────────────────┼───────────────────────┤
│ Install cmd          │ helm install app     │ helm install app      │
│                      │ repo/chart           │ oci://reg/chart       │
├──────────────────────┼──────────────────────┼───────────────────────┤
│ Maturity             │ Legacy (still works) │ Modern (recommended)  │
├──────────────────────┼──────────────────────┼───────────────────────┤
│ Search               │ helm search repo     │ Registry UI / API     │
└──────────────────────┴──────────────────────┴───────────────────────┘
```

## 📦 Method 3: ChartMuseum (Self-Hosted)

```bash
# ═══════════════════════════════════════════════════════
# Install ChartMuseum
# ═══════════════════════════════════════════════════════

# Via Helm (meta! 😄)
helm repo add chartmuseum https://chartmuseum.github.io/charts
helm install my-chartmuseum chartmuseum/chartmuseum \
  --set env.open.DISABLE_API=false \
  --set persistence.enabled=true

# Or Docker
docker run -d \
  -p 8080:8080 \
  -e STORAGE=local \
  -e STORAGE_LOCAL_ROOTDIR=/charts \
  -v ./charts:/charts \
  ghcr.io/helm/chartmuseum:latest

# ═══════════════════════════════════════════════════════
# Upload charts to ChartMuseum
# ═══════════════════════════════════════════════════════

# Via API
curl --data-binary "@my-chart-1.0.0.tgz" http://localhost:8080/api/charts

# Via helm-push plugin
helm plugin install https://github.com/chartmuseum/helm-push
helm cm-push my-chart-1.0.0.tgz my-chartmuseum

# ═══════════════════════════════════════════════════════
# Use ChartMuseum
# ═══════════════════════════════════════════════════════
helm repo add my-chartmuseum http://localhost:8080
helm repo update
helm search repo my-chartmuseum/
helm install my-app my-chartmuseum/my-chart
```

## 🔐 Private Repositories

```bash
# ═══════════════════════════════════════════════════════
# AUTHENTICATION OPTIONS
# ═══════════════════════════════════════════════════════

# Classic repo with basic auth
helm repo add private https://charts.example.com \
  --username admin \
  --password s3cret

# Classic repo with TLS certificate
helm repo add private https://charts.example.com \
  --ca-file ca.crt \
  --cert-file client.crt \
  --key-file client.key

# OCI registry login
helm registry login registry.example.com \
  --username admin \
  --password s3cret

# AWS ECR
aws ecr get-login-password | \
  helm registry login --username AWS --password-stdin \
  123456789.dkr.ecr.us-east-1.amazonaws.com

# Google Artifact Registry
gcloud auth print-access-token | \
  helm registry login -u oauth2accesstoken --password-stdin \
  us-docker.pkg.dev

# GitHub Container Registry
echo $GITHUB_TOKEN | \
  helm registry login ghcr.io --username myuser --password-stdin
```

## 🏗️ CI/CD: Automated Chart Publishing

### GitHub Actions Example:

```yaml
# .github/workflows/release-chart.yml
name: Release Helm Chart

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install Helm
        uses: azure/setup-helm@v4

      - name: Lint chart
        run: helm lint ./charts/my-app

      - name: Package chart
        run: helm package ./charts/my-app

      - name: Login to GHCR
        run: |
          echo "${{ secrets.GITHUB_TOKEN }}" | \
            helm registry login ghcr.io --username ${{ github.actor }} --password-stdin

      - name: Push to GHCR
        run: |
          helm push my-app-*.tgz oci://ghcr.io/${{ github.repository_owner }}/charts
```

### GitHub Pages Auto-Publish:

```yaml
# .github/workflows/publish-charts.yml
name: Publish Helm Charts

on:
  push:
    branches: [main]
    paths: ['charts/**']

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Install Helm
        uses: azure/setup-helm@v4

      - name: Configure Git
        run: |
          git config user.name "$GITHUB_ACTOR"
          git config user.email "$GITHUB_ACTOR@users.noreply.github.com"

      - name: Run chart-releaser
        uses: helm/chart-releaser-action@v1.6.0
        env:
          CR_TOKEN: "${{ secrets.GITHUB_TOKEN }}"
```

## 🧠 Knowledge Check

```
Q1: What are the two main types of chart repositories?
A:  Classic HTTP repos (with index.yaml) and
    OCI registries (container registries).

Q2: How do you push a chart to an OCI registry?
A:  helm push my-chart-1.0.0.tgz oci://registry/path

Q3: Do you need 'helm repo add' for OCI charts?
A:  No! You reference the full oci:// URL directly.

Q4: What is Artifact Hub?
A:  A search engine at artifacthub.io that indexes
    charts from many repositories.

Q5: What tool auto-generates index.yaml?
A:  helm repo index <directory> --url <base-url>
```

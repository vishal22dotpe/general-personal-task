# DevOps-Service — Landing Page

A modern, responsive landing page for **DevOps-Service**, your trusted DevOps partner for startups and scale-ups.

> Ship Faster. Scale Smarter. Stay Reliable.

## ✨ Features

- Sticky, blurred navigation bar with mobile hamburger menu
- Hero section with gradient headline and tech badges
- **Services** grid — CI/CD, Kubernetes, Cloud Migration, Multi-Cloud Setup, IaC, 24/7 Monitoring
- **Tech Stack** chips — AWS, ELK, GCP, Kubernetes, Docker, Terraform, Ansible, GitHub Actions, ArgoCD, Prometheus, Grafana, Helm
- **Why Us** feature cards — Fast Delivery, Battle-Tested Infra, Always-On Support
- Call-to-action section + multi-column footer
- Fully responsive (desktop → mobile) with a dark, modern aesthetic

## 🗂️ Project Structure

```
.
├── index.html    # Page markup and content
├── styles.css    # Styling, layout, and responsive rules
├── script.js     # Mobile menu toggle + footer year
└── README.md
```

## 🚀 Run Locally

No build step required — it's plain HTML/CSS/JS.

```bash
# Option 1: just open the file
open index.html

# Option 2: serve with a simple local server
python3 -m http.server 8000
# then visit http://localhost:8000
```

## 🌐 Deploy (free)

Drag-and-drop or connect this repo to any static host:

- **Vercel** — import the repo, deploy instantly
- **Netlify** — drag the folder into the dashboard
- **GitHub Pages** — enable Pages on the `main` branch

Pure HTML, CSS, and vanilla JavaScript. No frameworks, no dependencies.
